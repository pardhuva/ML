//distance based algorithms in ml 
  Distance-based algorithms are ML methods that use the idea of distance or similarity between data points to make decisions — whether to classify, group, or predict.
   They assume that similar data points (close in distance) have similar outputs or belong to the same group.

    | ML Category                                  | Examples                      | How distance is used                                                             |
    | -------------------------------------------- | ----------------------------- | -------------------------------------------------------------------------------- |
    | **Classification** (Supervised)              | KNN, SVM, Neural Networks     | Distance or similarity determines how a new point relates to known labeled data. |
    | **Regression** (Supervised)                  | KNN Regression, RBF Networks  | Nearby data points (in terms of distance) influence the predicted value.         |
    | **Clustering** (Unsupervised)                | K-Means, Hierarchical, DBSCAN | Groups points that are close together; defines clusters using distance.          |
    | **Anomaly Detection** (Unsupervised)         | LOF (Local Outlier Factor)    | Detects points that are *far* from all others — considered anomalies.            |
    | **Dimensionality Reduction / Visualization** | t-SNE, MDS, Isomap            | Preserves pairwise distances when reducing data to 2D/3D for visualization.      |
  
    not only for classification or regression 
    but also for unsupervised tasks that rely on measurign similarity

    Distance-based algorithms are models that learn or decide based on how close or similar data points are — used not only for classification and regression, but also for clustering, anomaly detection, and visualization.

//what is Decision tree?
    A Decision Tree is a supervised learning algorithm used for both classification and regression tasks.
     
     A Decision Tree is simply a hierarchical set of rules for making decisions.
        Each node asks a question about one attribute,
        and each branch represents an answer to that question.

        You move from the root (top) → leaves (bottom), making decisions step by step.
    flowchart :
      . Each internal node represents a test on an attribute (feature).
      . Each branch represents the outcome of that test.
      . Each leaf node represents a class label (for classification) or predicted value (for regression).
    
    ex: simple classification 

                IsTemperatureHot?
                 /            \
              Yes              No
           Play?Yes         IsWindy?
                           /       \
                        Yes         No
                      Play?No     Play?Yes

    So, the model is literally a set of if-else rules that make decisions.

    b) simplicity 
      easy to visualize

  no need for feature scaling 
  can handle both numerical and categorical data 
  works well even with missing data

//How is a decision tree constructed ?(induction)
    The process of building the tree is called Decision Tree Induction.
    steps :
    1. start with entire dataset -> this becomes the root node.
    2. select the best attribute to split the data - based on some measures like 
        . information gain(ID3 algorithm)
        . Gain Ration(C4.5)
        . Gini Index(CART)
    3. split the data into subsets based on the attribute.(Create branches for each possible value of that attribute.)
    4. repeat recursively for each subset(branch) until 
        . all instances in a subset belong to the same class 
        . no remaining attributes 
        . tree depth limit reached 

   splitting criteria 
    | Algorithm | Splitting Measure                   | Type                        |
    | --------- | ----------------------------------- | --------------------------- |
    | **ID3**   | Information Gain (based on Entropy) | Classification              |
    | **C4.5**  | Gain Ratio                          | Classification              |
    | **CART**  | Gini Index                          | Classification & Regression |

//nature of decision tree induction 
   these decisoion tree alsos use top-down recursive divide-and-conquer method.
    . start at the top(entire dataset=root)
    . split into subsets(children)
    . each node represents a subset of the training data 
    . continue recursively until nodes are pure 

    this is greedy process - it doesnt backtrack or reconsider previous choices 

//purity and impurity 
  pure node -> all samples belong to the same class 
    (eg: all = yes )
  impure node -> mized classes (yes and no)

  we measure impurity using mathematical measures like 
    1. entropy (in ID3)
          i(N) = - sigma(P(wj)log P(wj))
    2. Gini index (in CART)
          i(N) = 1- sigma(P^2(wj))
    3. Misclassification impurity 

//impurity measures 
    Let’s say:
        p₁ = proportion of “Yes”
        p₂ = proportion of “No”
      
        | Measure               | Formula                    | Range   | Max Impurity |
        | --------------------- | -------------------------- | ------- | ------------ |
        | **Entropy**           | -p₁ log₂(p₁) - p₂ log₂(p₂) | [0,1]   | 1            |
        | **Gini**              | 1 - (p₁² + p₂²)            | [0,0.5] | 0.5          |
        | **Misclassification** | 1 - max(p₁, p₂)            | [0,0.5] | 0.5          |
     
     More impurity = more mixed
     Less impurity = closer to pure

//choosing the best attribute (information gain)
   We choose the attribute that reduces impurity the most after splitting.
   Information Gain (ID3):

              Gain(A)=Entropy(Parent)−Weighted Avg(Entropy of Children) 

        Where: 
            S  = total dataset
            Sv = subset where attribute 
            Entropy(S) = −p1​log2​(p1​)−p2​log2​(p2​)
            Weighted AVG(entropy) = sigma(|Sv|/|S|) * Entropy(Sv)

        best attribute = the one givign highest Gain(A) 
        this makes the data purer faster 


//choosing the best attribute (Gain ratio)
     C4.5 noticed that attributes with many distinct values (like “Customer_ID”) can artificially get high Information Gain — even if they’re not meaningful.
     So it penalizes such attributes using Split Information.

      Step 1: Split Information (Intrinsic Info)
           splitInfo(A) = - sigma(|Sv|/|S|)*log|Sv|/|S|
      Step 2: Gain Ratio Formula 
              GainRatio(A) = Gain(A)/splitInfo(A)
     C4.5 chooses the attribute with the highest Gain Ratio.
     ID3 → only uses Gain
     C4.5 → uses Gain Ratio (normalized Gain)

// choosing the best attribute (Gini Index (CART))
     CART (Classification and Regression Trees) uses Gini Index instead of Entropy to measure impurity.
     It’s simpler to compute and works well for both classification and regression.

     formula for a node 
        Gini(S) = 1- sigma(pi)^2 i-> 1 to c 
          where 
             c -  number of classes
             pi = proportion of class 
     After splitting by attribute A:
        Ginisplit(A) = sigma(|Sv|/|S|)*Gini(Sv)
     Gini Gain (impurity reduction):
        GainGini(A) = Gini(S) - Ginisplit(A)

    CART chooses the attribute with the smallest Gini Index (or highest Gini Gain). 

    | Algorithm | Measure Used               | Formula                                          | Chooses                         |
    | --------- | -------------------------- | ------------------------------------------------ | ------------------------------- |
    | **ID3**   | Entropy + Information Gain | ( Gain(A) = Entropy(S) - \sum p_v Entropy(S_v) ) | Highest Gain                    |
    | **C4.5**  | Gain Ratio                 | ( GainRatio(A) = \frac{Gain(A)}{SplitInfo(A)} )  | Highest Gain Ratio              |
    | **CART**  | Gini Index                 | ( Gini(S) = 1 - \sum p_i^2 )                     | Lowest Gini / Highest Gini Gain |

//scalability and variants 
   When datasets are very large, classical methods (ID3, C4.5, CART) can be slow.
   So, specialized algorithms were developed:

    | Algorithm      | Idea                                                    |
    | -------------- | ------------------------------------------------------- |
    | **SLIQ**       | Builds attribute index lists                            |
    | **SPRINT**     | Similar, uses disk-based storage                        |
    | **PUBLIC**     | Combines splitting + pruning                            |
    | **RainForest** | Separates scalability from tree quality, uses AVC-lists |

 //drawbacks 
    . Decision Trees are axis-parallel (they split only along one attribute at a time)
       can’t represent diagonal or curved boundaries well.
    .  For continuous-valued attributes, we must find cut-points (like CART does).

overview 
  Step-by-Step Overview of Decision Tree Building

  Step 1: Take the Training Data
         Your dataset has:
             Input attributes (like Age, Income, Student, Credit Rating)
             Target/output label (like Buys_Computer = Yes/No)
  step2: Choose the Best Attribute to Split
      You test each attribute using one of these impurity measures:
        | Algorithm | Measure Used               |
        | --------- | -------------------------- |
        | **ID3**   | Information Gain (Entropy) |
        | **C4.5**  | Gain Ratio                 |
        | **CART**  | Gini Index                 |
    Choose the attribute that best reduces impurity (i.e., makes data purer after split).
     That becomes the root node of the tree.

   step3: Repeat Recursively
         For each branch (child node):
            Take the subset of data corresponding to that branch.
            Again, find the next best attribute to split.
            Keep doing this until:
                The data in a node is pure (only one class), or
                No more attributes left, or
                The gain becomes too small.
                This recursive splitting is how the decision tree grows.
        This recursive splitting is how the decision tree grows.

  Step 4: Compute Impurity at Every Node  
      Each time you split:
             Compute Entropy / Gini before and after split.
             Decide if the split is worth it.
       If impurity doesn’t reduce much — stop splitting.

  step5:   Handle Overfitting
     Once the tree is fully grown:
         It might start memorizing the training data (too detailed, zero generalization).
      To prevent that:
          🔹 Pre-Pruning
            Stop early if:
            Information Gain < threshold
            Node has very few samples
            Max depth reached
           Post-Pruning
          Build full tree first → then cut unnecessary branches using validation data.

   step6:  Final Model = Decision Tree Rules
       Once the tree is ready: Each path from root → leaf becomes an IF–THEN rule.

        IF Age <= 30 AND Student = yes THEN Buys_Computer = yes
     IF Age > 40 AND Credit_Rating = excellent THEN Buys_Computer = no

     These are your classification rules used on new test data.
    
   step7: Test the Model
       Use the test dataset (unseen data) to check:
         Accuracy
         Precision/Recall
         Overfitting (if training accuracy >> test accuracy)
    
    Decision Tree training =
    choose best split → reduce impurity → repeat → prune → get clean rules.
