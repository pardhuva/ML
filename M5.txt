   then gradeint is delta f = (delta(f)/delta(x) , delta(f)/delta(y) .....)

 2️⃣ Interpretation of Gradient

    Direction: The gradient points toward the steepest increase of the function.
    Magnitude: Tells how steep the slope is in that direction.

 using gradient for optimization 
 1. Maximization problem (find maximum value of f):
       Move in the direction of the gradient → function increases fastest.
 2. Minimization problem (find minimum value of f):
       Move in the direction of negative gradient → function decreases fastest.

So, the gradient tells you which direction is “best” depending on whether you want to maximize or minimize the function.

Gradient Descent vs Newtons Descent 

    | Aspect                             | **Gradient Descent**                  | **Newton's Method**                               |
    | ---------------------------------- | ------------------------------------- | ------------------------------------------------- |
    | **Uses**                           | First derivative (gradient)           | First and second derivatives (gradient + Hessian) |
    | **Update Rule**                    | $x = x - \alpha \cdot f'(x)$          | $x = x - \frac{f'(x)}{f''(x)}$                    |
    | **Convergence Speed**              | Slower (linear convergence)           | Faster (quadratic convergence)                    |
    | **Best For**                       | Large-scale problems, noisy gradients | Small problems, smooth and well-behaved functions |
    | **Computational Cost**             | Low (no second derivative needed)     | High (needs Hessian matrix in multivariate case)  |
    | **Requires Learning Rate?**        | ✅ Yes                                 | ❌ No (automatically finds optimal step size)      |
    | **Can get stuck in flat regions?** | ✅ Yes                                 | ❌ Less likely                                     |

//linearly seperable data 
Data is linearly separable if you can draw a straight line (or hyperplane) 
 that completely separates the points of one class from the other in the feature space.
    in 2d it its a straight line 
    in 3d its plane 
    in n-d its called a hyperplane 

    | Concept                 | Explanation                                              |
    | ----------------------- | -------------------------------------------------------- |
    | Linearly Separable      | Can separate classes with a **straight line/hyperplane** |
    | Not Linearly Separable  | **No straight line** can perfectly separate classes      |
    | Perceptron works if     | Data is linearly separable                               |
    | Solution for non-linear | Multi-layer perceptron, kernel trick                     |


//summaryy 
  Perceptron Learning for Linearly Separable Data :
   The goal: Find the decision boundary (weights 𝑤 and bias b) that separates the two classes.
   
   Since the data is linearly separable, the perceptron will converge to some solution

1.Standard (iterative) perceptron algorithm 
   Start with random weights w adn bias b 
   for each input xi :
       compute ouput y^ = step(w.xi +b)
       if ouput != target yi 
         .updates weights nad bias immediately 
             w = w + alpha*yi*xi
             b = b + alpha*yi
    Repeat until all points are classified correctly.
    Key: Updates happen immediately after each misclassification.

2.batch perceptron 
   Instead of updating after each sample, sum all updates over the whole dataset first:
    delta (w) = sum of yi*xi 
    delta (b) = sum of yi
    Where 
   M = set of misclassified samples.
  Update once per iteration using the sum.
  Key: More stable updates, good for batch processing.

3. single sample correction with normalized /augmented data      
    Augment data: Include bias in the input vector x^
    Normalize data for better convergence.
   For each misclassified sample, update the weights immediately:
      w = w + alpha*yi*xi^
      yi = -1 or +1 
    Repeat until all samples are classified correctly.
    Key: This is essentially the standard perceptron rule but written in augmented normalized form, often easier to implement mathematically.

| Method                                          | Update Timing                   | Notes                                               |
| ----------------------------------------------- | ------------------------------- | --------------------------------------------------- |
| Standard Perceptron                             | After each misclassified sample | Simple, iterative                                   |
| Batch Perceptron                                | After processing all samples    | More stable, batch mode                             |
| Single Sample Correction (Augmented/Normalized) | After each misclassified sample | Uses augmented vector, often cleaner mathematically |
  
  Important: All three methods only work for linearly separable data. If the data isn’t separable, the weights won’t converge.

//convergence in gradient descendent 
  Imagine you have some data points and you want a line that fits them.
  You define error as the difference between your predictions and actual values (squared error).
  Gradient descent is like “walking downhill” on the error surface to minimize error.

  steps : 
   start with random waits w(slope,bias)
   compute gradient(slope of error w.r.t weights)
   Update weights slightly in the opposite direction of the gradient:
       wnew = wold - eeta*deltaE(W)
    repeat this until teh line stops chanign much -> convergence 

   Gradient descent gradually rotates and shifts the line until error is minimized.

perceptron vs linear regression(covergence/closed-form)
1.perceptron 
    Type: Classifier
    Output: Discrete — either Class 1 or Class 2
    Bias: Included (as part of the weights, usually with augmented input)
    Error: Only considers misclassification (0/1 error)
    Convergence: Only guaranteed if data is linearly separable
    Goal: Find a decision boundary (line/hyperplane) separating classes
2. Linear regression(Gradient descent /cloesd form)
    Type: Regression (not classification)
    Output: Continuous values (e.g., any real number)
    Bias: Included in weights if you add a column of ones in your data matrix
    Error: Minimizes squared error between predicted and actual values
    Convergence: Always (gradient descent) or exact solution (closed-form)
    Goal: Find weights that best fit the data points, not separate classes

  | Feature                | Perceptron                         | Linear Regression           |
| ---------------------- | ---------------------------------- | --------------------------- |
| Output                 | Class label (0/1 or +1/-1)         | Real-valued prediction      |
| Purpose                | Classification                     | Approximation / Prediction  |
| Bias                   | Explicit (augmented input)         | Included via 1-column in D  |
| Convergence guaranteed | Only if data is linearly separable | Always (or exact solution)  |
| Error considered       | Misclassification                  | Squared error               |
| Decision boundary      | Exists (line separating classes)   | No boundary; fits best line |

  Perceptron: “I only care if my answer is right or wrong. If wrong, I adjust weights.”
  Linear regression: “I care about how far off my answer is from the target. I adjust weights to minimize this distance.”
